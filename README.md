# outage-odesa: сборщик

Достаёт график отключений со страницы ДТЭК Одесские электросети и передаёт его Telegram-боту. Запускается ботом примерно раз в 15 минут через GitHub Actions; расписание самого GitHub служит запасным.

## Что делает запуск

1. Открывает страницу в Chromium (Playwright, до 3 попыток) и читает `window.DisconSchedule`. Если его нет в `window`, вырезает JSON из HTML. Ничего из страницы не исполняется, только `JSON.parse`.
2. Проверяет форму данных: есть `fact.data` и `preset.sch_names`, ключи суток похожи на unix-время.
3. Отправляет данные боту (до 3 попыток при сетевых ошибках и ответах 5xx). Если данные получить не удалось, отправляет отчёт об ошибке.

Запуск красный, только если бот недоступен, отверг токен (403) или не заданы секреты. Сбой источника красным запуском не помечается намеренно.

## Настройка

Секреты репозитория (Settings → Secrets and variables → Actions): `WORKER_URL` (адрес бота, без слэша в конце) и `INGEST_TOKEN` (общая с ботом случайная строка). Значения нигде не печатаются.

## Важно

- Репозиторий публичный, логи запусков тоже. Не добавляй сюда workflow с триггерами `pull_request_target` или `workflow_run`: они могут отдать секреты чужому коду.
- GitHub отключает расписание в публичных репозиториях после 60 дней без активности (сами запуски активностью не считаются). Тогда во вкладке Actions появляется кнопка включения; раз в месяц достаточно мелкого коммита.
- Запуск вручную: Actions → Collect → Run workflow.

## Файлы

- `scripts/collect.mjs`: сборщик.
- `scripts/lib/extract.mjs`: разбор и проверка данных.
- `scripts/probe.mjs` и `.github/workflows/probe.yml`: одноразовая проверка доступности страницы (вручную).
- `tests/`: `npm test` (быстрые, без сети) и `npm run test:e2e` (настоящий Chromium, локальные заглушки).
